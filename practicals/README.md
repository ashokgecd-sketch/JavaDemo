# Java Practicals

Each numbered Java file follows the experiment order in the supplied list: `Practical1.java` is 1.1 and `Practical54.java` is 10.4. Compile a non-JavaFX practical with `javac PracticalN.java`, then run it with `java PracticalN` (from this directory). Package exercises are in `Practical45/` and `Practical46/` and include their own run instructions in comments.
